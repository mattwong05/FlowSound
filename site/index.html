FAQ

Small answers before you download.

Does FlowSound record audio?

No. FlowSound only computes local audio activity levels.

Does it upload anything?

No. FlowSound has no analytics, no server, and no upload feature.

Does it work with Spotify?

Yes. FlowSound supports Apple Music and Spotify through local AppleScript.

Can it support other music apps?

Apple Music and Spotify are official. Netease Cloud Music is experimental and uses menu commands plus Core Audio output feedback, so it may break if the app menu changes.

Does it support Chinese?

Yes. FlowSound supports English and Simplified Chinese, with automatic language selection and a manual preference.

Which version should I download?

Choose the 0.18.0 preview to try the redesigned interface and reliability updates. The previous stable channel remains at 0.15.1. Read each release’s installation notes before opening it.

Does it work on macOS 26 and 27?

FlowSound targets macOS 15 and later. A user reported that 0.17.0 runs on macOS 26; 0.18.0 has been built and its native interface reviewed on macOS 26. Building with the macOS 27 SDK does not establish macOS 27 runtime compatibility, which still needs testing.

Why does macOS warn me when opening it?

The 0.18.0 preview is ad-hoc signed and not notarized by Apple. Gatekeeper may block it on first open. Review the GitHub release notes and checksum before deciding whether to run it.
