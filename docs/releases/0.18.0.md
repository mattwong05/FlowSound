# FlowSound 0.18.0

**FlowSound 0.18.0 is the current official release.** It uses ad-hoc signing and is distributed without Developer ID signing or Apple notarization. macOS may require manual approval on first launch.

**FlowSound 0.18.0 现为正式版和默认下载版本。** 本项目采用 ad-hoc 签名发布，不使用 Developer ID，也未经过 Apple 公证；首次打开时可能需要在系统设置中手动批准。

## What's new / 更新内容

- Native Settings toolbar with General, Applications, Sound and Tools panes. 应用规则分为监听与忽略两列，标题独立，添加与移除按钮对齐。
- Dedicated sound timing sliders with precise numeric inputs. 声音调节支持滑块与精确输入，所有设置在保存后生效，取消可放弃修改。
- Clearer Diagnostics and a compact About window, in English/Chinese and light/dark appearances. 诊断与关于窗口同步更新，兼顾中英文及浅深色。
- Includes reliability improvements since the previous release: bounded monitor recovery, stale-operation cancellation, player-instance restore ownership, persistent empty rules and clearer permission failures. 同时包含监听恢复、过期操作取消、播放恢复归属、空规则保存与权限状态等修复。

Full changes: [CHANGELOG](https://github.com/mattwong05/FlowSound/blob/v0.18.0/CHANGELOG.md).

## Download and install / 下载与安装

Download `FlowSound-0.18.0.zip`, `SHA256SUMS.txt` and `BUILD_INFO.txt` from this release. The app contains Apple Silicon and Intel executables and targets macOS 15 or newer.

下载本发布页的压缩包、校验文件和构建信息。应用包含 Apple Silicon 与 Intel 架构，最低目标系统为 macOS 15。

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Quit the previous FlowSound instance before replacing the app. Unzip, move `FlowSound.app` to `/Applications`, and follow [installation and permissions](https://github.com/mattwong05/FlowSound/blob/v0.18.0/INSTALL.md). Existing settings are retained. Netease Cloud Music remains experimental and may need Accessibility access.

If macOS blocks first launch, open the app once, then go to **System Settings > Privacy & Security > Open Anyway** and confirm. This approves FlowSound individually; no system-wide security change is needed.

替换前先退出旧版 FlowSound。解压并移入“应用程序”。如首次打开被拦截，请进入“系统设置 → 隐私与安全 → 仍要打开”并确认。原有设置会保留；网易云音乐仍为实验性支持。
