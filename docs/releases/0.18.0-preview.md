# FlowSound 0.18.0 — Public Preview / 公开预览版

**This is an ad-hoc signed preview, not a Developer ID signed or notarized release. macOS may require manual approval to open it.** The existing 0.15.1 release remains the default download.

**这是 ad-hoc 签名、未经 Apple 公证的公开预览版，macOS 可能要求手动批准打开。** 原有 0.15.1 仍保留为默认发布版本。

## What's new / 更新内容

- Native Settings toolbar with General, Applications, Sound and Tools panes. 应用规则分为监听与忽略两列，标题独立，添加与移除按钮对齐。
- Dedicated sound timing sliders with precise numeric inputs. 声音调节支持滑块与精确输入，所有设置在保存后生效，取消可放弃修改。
- Clearer Diagnostics and a compact About window, in English/Chinese and light/dark appearances. 诊断与关于窗口同步更新，兼顾中英文及浅深色。
- Includes the unreleased reliability work since 0.15.1: bounded monitor recovery, stale-operation cancellation, player-instance restore ownership, persistent empty rules and clearer permission failures. 同时包含监听恢复、过期操作取消、播放恢复归属、空规则保存与权限状态等修复。

Full changes: [CHANGELOG](https://github.com/mattwong05/FlowSound/blob/preview-0.18.0/CHANGELOG.md).

## Download and install / 下载与安装

Download `FlowSound-0.18.0.zip`, `SHA256SUMS.txt` and `BUILD_INFO.txt` from this release. The app contains Apple Silicon and Intel executables and targets macOS 15 or newer.

下载本发布页的压缩包、校验文件和构建信息。应用包含 Apple Silicon 与 Intel 架构，最低目标系统为 macOS 15。

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Quit the previous FlowSound instance before replacing the app. Unzip, move `FlowSound.app` to `/Applications`, and follow [installation and permissions](https://github.com/mattwong05/FlowSound/blob/preview-0.18.0/INSTALL.md). Existing settings are retained. Netease Cloud Music remains experimental and may need Accessibility access.

替换前先退出旧版 FlowSound。解压并移入“应用程序”，参考上述安装与权限说明。原有设置会保留；网易云音乐仍为实验性支持。
